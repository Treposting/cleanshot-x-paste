ShotPaste is a free, open-source menu-bar app for Mac. It takes screenshots and screen recordings, and it remembers everything you copy.

Download for Mac Source on GitHub

Runs on macOS 13 or later, on Apple Silicon and Intel. MIT licensed.

Seven things it does from the menu bar

Every action has a global shortcut, and you can change any of them in Settings.

  • Capture

    Grab an area, a window or the whole screen. While selecting, press Space to switch to window mode.

    ⌥⇧⌘4

  • Record

    Record to MP4 at 30 or 60 fps, with computer audio if you want it. Save any recording as a looping GIF.

    ⌥⇧⌘6

  • Mark up

    Add arrows, boxes, text, highlights and numbered steps. Pixelate anything private before you send it.

    from the overlay

  • Read

    Select part of the screen and copy the text in it. Recognition runs on your Mac, with no upload.

    ⌥⇧⌘2

  • Pin

    Float a screenshot above every window while you work. Scroll on it to fade it, double-click to close it.

    from the overlay

  • Keep

    Text, links, images and files you copy are saved with the app they came from, and they stay searchable.

    ⇧⌘V

  • Paste

    Pick an item from your history and it goes straight into the app you were typing in.

Clipboard history along the bottom of your screen

Press ⇧⌘V and type to search. Arrow keys move, Return pastes. The app you were in stays in front the whole time.

Screenshots land here too

Copy a capture from the overlay and it joins your history, so last week's screenshot is still a search away.

Passwords are skipped

Password managers tag what they copy with org.nspasteboard.ConcealedType. ShotPaste never records those items.

Stays on your Mac

No account, no sync and no network requests. History lives in your Library folder, and you can pause it from the menu bar.

Install

Takes about a minute. Releases are universal builds for Apple Silicon and Intel.

  1. Download the DMG

    Get the latest release from GitHub, open it, and drag ShotPaste into Applications.

  2. Open it once with right-click

    Releases aren't notarized by Apple yet, so macOS asks you to confirm the first launch: right-click the app and choose Open.

  3. Allow Screen Recording

    macOS asks the first time you capture. Accessibility is optional; it lets ShotPaste paste into other apps for you.

# Or build it yourself (Xcode 15+)
$ git clone https://github.com/Treposting/cleanshot-x-paste.git
$ cd cleanshot-x-paste
$ make run     # build and launch
$ make dmg     # universal DMG in build/
